# infra-scripts

Small scripts I use for infrastructure work.

Most of this repository came from the same situation: I had to check something more than once, got tired of doing it by hand, and turned it into a script.

Nothing fancy. Just useful stuff for Linux, networks, monitoring, backups and VoIP.

## What's here

### `backup/`
Backup scripts for daily and manual routines.

### `network/`
Network checks and troubleshooting helpers.

### `monitoramento/`
Zabbix-related checks and discovery scripts.

### `voip/`
Scripts related to VoIP environments.

## How I use this repo

This is not a collection of copy/paste one-liners. I keep scripts here when they solve a problem I actually had and I think I will need the logic again.

I also use it to improve old scripts when I find a better way to do the same job.

If something here looks simple, that's usually the point.
